Проект **«ЯТЬ»** — это цифровая лаборатория, посвященная сохранению и изучению дореволюционной русской орфографии, а также универсальный «швейцарский нож» для работы с данными, физическими величинами и текстом. 

Мы верим, что красота языка кроется не только в звуках, но и в буквах, и стремимся сделать процесс обращения к дореформенному письму легким и доступным для каждого.

## Основные возможности

* **Интеллектуальный переводчик:** Автоматическая реконструкция текста по правилам, действовавшим до 1918 года.
* **Двусторонний режим:** Перевод из современной орфографии в дореволюционную и расшифровка старинных грамот.
* **Образовательная база:** Статьи по истории, правилам языка и ИТ-технологиям.
* **Конфиденциальность:** Мы не храним ваши тексты и предлагаем автономные версии инструментов для полной независимости.

## Инструментарий

Проект включает в себя широкий набор цифровых средств:

1. **Физика и законы мироздания:** Калькуляторы закона Ома, II закона Ньютона, момента силы, ускорения и кинематики.
2. **Специализированные калькуляторы:** Расчет выплат (зарплата), калорий (BMR), стоимости токенов API, разницы дат и параметров битов.
3. **Конвертеры:** Системы счисления, валюты, единицы измерения, цветовые палитры (HEX/RGB) и римские цифры.
4. **Работа с данными:** Текстовые утилиты, кодирование (Base64, URL), криптография (MD5, SHA-256), генератор QR-кодов и азбука Морзе.

## API проекта

Интегрируйте возможности переводчика «ЯТЬ» в свои приложения.

* **Endpoint:** `https://yiat.vercel.app/api/v1/translate`
* **Метод:** `POST`
* **Аутентификация:** Заголовок `x-api-key`.

### Пример на Python:
```python
import requests

url = "[https://yiat.vercel.app/api/v1/translate](https://yiat.vercel.app/api/v1/translate)"
headers = {
    "x-api-key": "тут_ваш_API",
    "Content-Type": "application/json"
}
payload = {"text": "Фёдор пошёл в лес."}

response = requests.post(url, json=payload, headers=headers)
print(response.json()['translated']) # Ѳеодоръ пошёлъ въ лѣсъ.
```
